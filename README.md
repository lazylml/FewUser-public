# FewUser (Public Release)

This repository contains the public code for the **FewUser** project.

## Data Availability

Due to GitHub file size limits, the dataset used in this project is hosted externally.

The data can be accessed and downloaded via Google Drive:
https://drive.google.com/drive/folders/1RM9AU83vZqSVD7KBVvApPQY-Ki-s9tAy?usp=drive_link

The shared link provides read-only access and does not require a Google account.

## Notes

- The dataset is provided for **research and academic use only**.
- Please refer to the paper for detailed descriptions of data preprocessing and experimental settings.
- If you encounter any issues accessing the data, feel free to open an issue in this repository.
